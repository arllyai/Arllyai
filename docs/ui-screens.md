# 4) Sample UI Screens

1. **Onboarding + Goal Setup**
   - Language pair selection
   - Daily goal slider (5/10/15/20 mins)
   - Placement mini-quiz

2. **Home / Learning Path**
   - Unit path map (Duolingo-style nodes)
   - Current streak flame, hearts, XP bar at top
   - CTA: Continue lesson

3. **Lesson Player**
   - Exercise card (MCQ/fill/order/listen/speak)
   - Inline AI hint button
   - Pronunciation listen/repeat control (ElevenLabs audio)

4. **Lesson Results**
   - XP earned animation
   - Mistakes review with AI explanations
   - “Practice weak words” quick action

5. **AI Tutor Chat**
   - Contextual conversation mode
   - Grammar explain mode (simple wording)
   - Personalized corrections pinned as tips

6. **Progress Dashboard**
   - Accuracy trend chart
   - Weak areas heatmap (tense, vocab themes, pronunciation)
   - Recommended lessons generated daily

7. **Leaderboard & Badges**
   - Daily/weekly tabs
   - Friend/community ranking
   - Badge gallery with unlock conditions
